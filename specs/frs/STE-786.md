# The drift probe sees an FR whose Jira ticket is done

## Summary

Shipping one FR marks its Jira ticket done but leaves the FR file active.
That state is expected until the whole milestone is archived.
The drift probe reads a Jira listing that leaves out done tickets.
So it calls the FR an orphan and fails the gate on a healthy tree.
The fix fetches the tickets the active FRs are bound to as well.
A bound ticket that is closed is then not an orphan.

## Requirement

In Jira mode, probe #49's listing includes every ticket an active local FR binds, and a closed bound ticket never makes its FR a `local-orphan`.

## Acceptance Criteria

- AC-STE-786.1: A new front door, `tracker_listing_query.ts jira <projectRoot> <projectKey>`, prints the JQL `project = <KEY> AND (statusCategory != Done OR key in (<keys>))`, where the keys are the Jira keys bound by active local FRs, sorted. With no bound keys it prints the old JQL unchanged.
- AC-STE-786.2: `adapters/jira.md` `list_active_frs` and the probe #49 instruction in `skills/gate-check/SKILL.md` run that front door and use its JQL.
- AC-STE-786.3: An active local FR bound to a ticket present on the page with status category `done` is not a `local-orphan`, and no tracker-orphan row is made for that ticket. An active FR whose bound key is absent from the page is still a `local-orphan`.
- AC-STE-786.4: Linear behaviour is unchanged: its listing already carries closed issues, and the same closed-bound case passes there too.
- AC-STE-786.5: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the trunk baseline by name.

## Technical Design

The front door reads active FR frontmatter for `tracker.jira` keys and composes the JQL, escaping nothing because Jira keys are plain identifiers checked by pattern. In the reconcile helper, the tracker set used for the local-orphan test includes closed tickets, while the tracker-orphan pass keeps skipping them.

## Testing

Unit tests for the JQL builder (no keys, some keys, a malformed key refused), and reconcile tests with a page holding a closed bound ticket, an open one and a missing one.
