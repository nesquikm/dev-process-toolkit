# A refusal names the plugin copy that ran

## Summary

A command run from another plugin copy prints a normal receipt.
The write gate ignored that receipt and gave the wrong reason.
Its refusal now names the copy that ran and the copy it trusts.
The other receipt stays untrusted.

## Requirement

When a deciding command in the session ran from another copy of this plugin, a refusal by the tracker-write gate says so and names both copies, and the receipt that run wrote still authorises nothing.

## Acceptance Criteria

- AC-STE-868.1: A Bash command that `invokedDecidingModule` would accept but for a module path in another copy of this plugin adds a note to the refusal. The note names that copy's root and version and the hook's own root and version, and it says to rerun the command from the hook's own copy. Another copy is a directory whose manifest at `.claude-plugin/plugin.json` carries this plugin's name.
- AC-STE-868.2: Such a command is left out of the "not a plain invocation" count and citation. A command that is also not plain keeps today's note and gains none.
- AC-STE-868.3: An absent, unreadable or versionless manifest of a path under another `dev-process-toolkit` cache directory is reported as version unknown, and a same-named module file outside any plugin copy keeps today's note.
- AC-STE-868.4: A later accepted run of the same module, with a result that ran, drops the note, as AC-STE-797.4 does for rejected commands.
- AC-STE-868.5: A receipt announced by another copy never permits a write, for the Epic close and for a ticket create alike, through the `.sh` wrapper, and the twin run from the hook's own copy permits.
- AC-STE-868.6: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the trunk baseline by name.

## Technical Design

`scanAnnouncements` classifies a rejected command by reading it through `bunInvocation` with the other root, taken from the module path's own plugin root. It records the foreign copy beside `rejected`, and the note writer prints one line per module for the latest run. Reading another manifest never throws out of the gate.

## Testing

Hook tests with two temporary plugin roots of different versions, one absent manifest and one same-named stray file, plus superseded and permit twins.

## Notes

Field report 2026-11-24: the stale-copy receipt hid the cause for a week. STE-607 fixed the trust rule; it is not relaxed.
