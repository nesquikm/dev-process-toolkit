# A bound tracker project changes only through the checked repoint rows

## Summary

A declaration run of the binding writer could silently re-point a repository to another tracker project or team.
Every door into the writer now refuses a changed project, a changed key-shaped Linear team, and an overwrite of a declared block missing its project line, unless the call comes from the repoint rows.
The repoint resumes only from a deferred project and refuses an absent one before any row, naming the way back.

## Requirement

Every door into writeTrackerSubsection must refuse three things unless the caller is the repoint rows route (`repoint: true`): changing a bound `project:`, changing a key-shaped Linear `team:`, and writing over a sub-section whose `project:` is missing while it still carries a declaration. The doors are the writer CLI, the repoint's declare and resume routes, and linear-team-key. The repoint resumes only from `project: <deferred>`. An absent project refuses before any row, with a remedy that either restores the line from git or binds it with the writer.

Covers B-1 (**high**) and B-5 (D-3, medium). Retires KNOWN DEFECT D-3 of STE-616: per operator ruling R4, the D-3 bullet in `specs/frs/archive/STE-616.md` gains one clause, "Fixed in `STE-645` (v2.92.0)", and no shipped CHANGELOG entry is edited.

## Technical Design

writeTrackerSubsection reads the current values before stripping the paragraph and checks them before the write. A single `repoint?: true` option waives the checks; without it TrackerBindingWriteError (NFR-10) is thrown on (a) two or more `project:` lines or a non-deferred project different from the one passed, (b) an absent project beside a declaration, (c) a different key-shaped, non-deferred Linear team (regex defined locally, avoiding the linear_team_key import cycle), (d) an empty project in-process. writeRepoint passes `repoint: true`; declare/resume does not; planTeamKey returns `key: null` on an undefined project. routeRepoint resumes only on the deferred sentinel and refuses an undefined project before any row.
