# A --no-tech run names its legal spec-research skip

## Summary

A spec run without technical design skips the related-spec research on purpose.
That legal skip emits no token, so it looks the same as a silent skip.
The dependency research already names its own skip with a token.
Spec research now does the same in the spec skill and the brainstorm skill.

## Requirement

`/spec-write --no-tech` and `/brainstorm --no-tech` emit `spec_research_skipped_no_tech` for the legal spec-research skip.

## Acceptance Criteria

- AC-STE-752.1: `skills/spec-write/SKILL.md` step 2.5 says that a `--no-tech` run **MUST emit `spec_research_skipped_no_tech`**, and states the complete four-token set for the step.
- AC-STE-752.2: `skills/brainstorm/SKILL.md` says the same for its `--no-tech` skip of the spec-research seed.
- AC-STE-752.3: `spec_research_skipped_no_tech` is registered in `CANONICAL_CAPABILITY_KEYS` with its owner, and `/spec-write`'s § 7 static map carries a row for it.
- AC-STE-752.4: The smoke `--no-tech` spec-write capture asserts `present spec_research_skipped_no_tech`.
- AC-STE-752.5: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the baseline by name.

## Technical Design

Mirrors `deps_research_skipped_no_tech`. One key in `closing_summary_capability_keys.ts`, two skill lines and one static map row.

## Testing

Registry and contract tests, written like the existing deps-research skip-token tests.

## Notes

Conformance 2026-11-17 F18, a repeat of 11-12.
