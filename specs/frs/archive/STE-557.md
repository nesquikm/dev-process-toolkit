# Lowering the unreachable pin costs one edit, not three

## Summary

The reachability probe rewards giving a module a front door by turning the gate red.

Its remedy is to lower a pinned count. Three surfaces state that count and must agree byte for byte.

One of them is a test whose name claims to guard the number while it compares two frozen literals to each other.

So the sanctioned direction is the expensive one.

## Requirement

The pinned ordered-and-unreachable count is stated as a literal in exactly one place. Every other surface derives from it or asserts against a frozen historical value that a later lowering cannot invalidate. The ceremony that governs a move — a rationale is owed, a raise is refused — is executed by the gate rather than described in prose. Lowering the pin is one edit; raising it stays forbidden.

## Acceptance Criteria

- AC-STE-557.1: `ORDERED_UNREACHABLE_PIN` is no longer assigned a numeric literal. It is derived from the head of `ORDERED_UNREACHABLE_PIN_LEDGER`, a newest-first list of every move the pin has made. Asserted two ways: the exported value equals the head entry's value, and the module source contains no `ORDERED_UNREACHABLE_PIN = <digits>` assignment.
- AC-STE-557.2: The ledger records the pin's measured history, not a recollection of it. Nine moves, taken from `git log -L` over the constant: 146 at its introduction, then 142, 139, 137, 136, 133, 131, 130 and 129. Every entry names the commit that made the move, and each named commit resolves in this repository — an audit trail that cannot be verified is decoration.
- AC-STE-557.3: `gradePinLedger` refuses a move whose rationale is blank and passes the same move once a rationale is present. Both halves asserted over fixtures, because the refusal alone is satisfied by a grader that refuses everything.
- AC-STE-557.4: `gradePinLedger` refuses a RAISE and names the reason — a raise admits one more order nobody can carry out. Asserted in its own leg, over its own fixture, separate from the lowering leg, so neither can carry the other.
- AC-STE-557.5: The ceremony is executed by the gate, not only by its own suite. `runModuleReachabilityProbe` grades the ledger it is handed and emits one error violation per refusal, in the NFR-10 shape probe #81 already uses. Asserted by handing the probe a raised ledger and a rationale-less ledger and reading the violations back; asserted vacuous — no refusal — for the shipped ledger.
- AC-STE-557.6: The sibling hard-code is gone. `tests/m140-ste-543-external-link-verdicts.test.ts` no longer asserts the live pin equals 129; it asserts that the ledger's entry for M140's own commit records 129 and that the live pin is at or below it. M140's historical claim survives; a later lowering no longer reds a file the lowering does not name.
- AC-STE-557.7: No shipped markdown restates the pinned count. `skills/gate-check/SKILL.md` keeps its disclosure that probe #81's own registration is in the class it counts, and keeps its description of where the pin lives, both without the number. A sweep over the shipped markdown trees asserts that no line naming the pin carries the pin's value, and that at least one such line exists — the sweep is worthless if nothing matches.
- AC-STE-557.8: The test that names the pin can fail on it. `tests/m141-ste-545-release-writer-door.test.ts`'s "the pin only ever FELL" leg reads the live pin and the live ledger instead of comparing 131 to 133. Mutation-verified: raising the ledger head reds that named leg. Measured at HEAD, mutating the constant to 128 left that leg green while seven other legs red — it is the wrong-subject shape this repository has now measured seven times.
- AC-STE-557.9: Falsifiability, in both directions, with the sibling observed. A RAISED ledger head kills AC.5's ceremony legs and the refusal names the raise; the same mutation leaves AC.1's one-home legs GREEN, because a raise does not move where the number lives and a mutation that reds everything attributes nothing. A well-formed LOWERING that nothing measured — it carries a rationale and a commit, so the ceremony passes it — still reds the count legs, and the run is asserted NOT to mention a raise, which is what keeps the two directions from being read as one. A control run with a harmless edit stays green. Each mutation run selects a single criterion by test name, which is also what stops this suite's own overlay legs from nesting.
- AC-STE-557.10: The tree-wide sweeps read the whole tree and this repository's own idiom. The walk covers the colocated `adapters/**/*.test.ts` suites as well as `tests/`, asserted rather than assumed, because one colocated suite already names the pin. The forbidden shape is matched in both the one-argument and the prevailing two-argument `expect(x, "message").toBe(n)` form, while `toBeLessThan` and `toBeLessThanOrEqual` against a frozen historical value stay permitted — those are how a suite says the pin was never raised.

## Technical Design

The pin becomes the head of a ledger of moves, each carrying a value, the commit that made it, and a rationale. Deriving the constant from the head leaves one literal where there were three.

A grader over that ledger states the ceremony as code: a raise is refused, a blank rationale is refused, a lowering with a reason passes. The probe calls the grader on the ledger it is handed, so a malformed ledger reds the gate rather than one suite.

Sibling suites stop asserting equality with a moving number. They assert against the ledger entry for their own milestone's commit, which is frozen by history and cannot be invalidated by a later lowering.

## Testing

The grader is driven over fixture ledgers, never over the shipped one, so what is graded is a changed world rather than a changed grader. The shipped ledger gets its own leg: it grades clean, and its head equals the exported constant.

The shipped-prose sweep walks the real markdown trees and reads the live pin, so it cannot pass by naming a stale number.

## Notes

The ledger's commits are short shas resolved against this repository. In a consumer checkout that history does not exist, so the resolution leg is scoped to this repository's own suite rather than shipped as a probe.
