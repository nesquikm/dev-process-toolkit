# The executing Epic mint prose names its label step and its join mode

## Summary

A live spec-writing run follows the skill, not the adapter documents, and the skill's description of the Epic mint was two steps behind the code.
It named two returned fields where the code returns three, it never mentioned the milestone label the mint writes, and it described a refusal that only the join mode raises while documenting a call that never asks for that mode.
The line is rewritten in place to match the adapters.

## Requirement
