# Fixture group 2: NDJSON-safe matching and subject-isolating staging

## Summary

Group two's pattern uses a wildcard that, on a streaming capture, runs straight through encoded newlines and matches text from unrelated paragraphs. In one run this produced a spurious pass in one sub-fixture and a false failure in another — same pattern, same run, opposite errors. The group also stages its test input in a way that trips two unrelated checks, so a red result cannot be attributed to the thing the group is meant to measure.

## Requirement

Group 2's matching is safe in both directions on NDJSON captures, and its staging isolates the subject so a failure names the right cause.

## Acceptance Criteria

- AC-STE-489.1: The group's patterns cannot span encoded newlines; sub-fixture 2a no longer matches spuriously and sub-fixture 2c, whose probe behaved correctly, now matches.
- AC-STE-489.2: Assertions reference the identifier form the runtime renders (`#26`), not the word `probe` followed by 26.
- AC-STE-489.3: The staging method no longer trips probe #22 `toolkit-bootstrap-committed` or probe #40 `needs_technical_review_consistency`, so the group's verdict is attributable to its own subject.
- AC-STE-489.4: Sub-fixture 2b is re-keyed from the aggregate verdict onto probe #26's own row, so it distinguishes its subject failing from the staging artefact failing.
- AC-STE-489.5: STE-483's harness proves each repaired assertion fails when its own subject misbehaves, in both directions.

## Technical Design

F9 measured: sub-fixtures 2a and 2c share `grep -E 'ADVISORY.*probe.*26|probe.*26.*ADVISORY'` against the raw capture. In raw NDJSON the escaped newline is two ordinary characters, so `.` matches through it and the pattern silently spans separate lines and paragraphs. In one run, 2a matched for exactly that reason (raw true, assistant-scoped false) while 2c, whose probe behaved identically and correctly, matched nothing. One spurious pass and one false failure from the same assertion in the same run is the cleanest possible demonstration that the method, not the subject, is at fault. Probe #26 itself was correct in all three sub-fixtures, so the STE-198 deprecation window is being honoured.

F12 measured: staging a minimal uncommitted FR under `specs/frs/` — the method 2a through 2c prescribe — trips probes #22 and #40, turning the aggregate verdict red on its own. 2b asserts against the aggregate, so it cannot distinguish its subject failing from the staging artefact failing. It passed only because probe #26's row was independently readable — right today, for a reason its assertion does not check.

## Testing

Both sub-fixtures run against the archived captures where they previously gave opposite wrong answers, and through STE-483's harness for the absent-subject direction. Staging fixture asserting probes #22 and #40 stay green. `bun test` full root.
