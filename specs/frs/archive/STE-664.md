# Voice and music providers

## Summary

The video pipeline speaks through ElevenLabs or Google text to speech, chosen per project.
Each script segment is voiced alone and returns word timings, so cuts land on a spoken word.
Both providers return the same timing shape, so nothing downstream cares which one ran.
Background music comes from ElevenLabs, a committed track, or nothing.
Failures name the provider and the missing key, never the key itself.

## Requirement

- **One interface.** `TtsProvider.synthesize(segment)` returns the audio file and word-level alignment `[{ word, start, end }]` in seconds; both adapters normalize to it.
- **ElevenLabs.** Uses the with-timestamps endpoint and turns character timings into word timings. `eleven_v4` ignores SSML `<break>`, so a `<break>` in script text is rewritten to `[short pause]` before the call.
- **Google.** Uses SSML with one `<mark>` per word and time-pointing, and turns the returned timepoints into word timings; `[short pause]` becomes a `<break>`.
- **Per segment.** One call per script segment, written to the video's work dir.
- **Music.** `elevenlabs` generates a track from a prompt built from style and duration; `file` uses the committed track; `none` produces no track.
- **Failures.** Auth errors refuse naming the provider and key variable; rate-limit and server errors retry on the canonical 1s + 2s + 4s schedule, then refuse.

## Acceptance Criteria

- AC-STE-664.1: Both adapters return `{ audioPath, alignment }`, where `alignment` is word entries with non-decreasing `start` ≤ `end` within the audio duration; a shared contract test runs against both adapters with recorded fixture responses.
- AC-STE-664.2: The ElevenLabs adapter sends one request per segment to the with-timestamps endpoint with the configured voice and model, and converts a fixture's character alignment into the expected word list, byte-compared.
- AC-STE-664.3: Script text `A<break time="1s"/>B` reaches the ElevenLabs request as `A [short pause] B`, and `[short pause]` reaches the Google request as `<break time="400ms"/>`.
- AC-STE-664.4: The Google adapter sends SSML with one `<mark name="w<i>"/>` per word and time-pointing enabled, and converts a fixture's timepoints into the expected word list.
- AC-STE-664.5: A three-segment script yields three provider calls and writes `segments/<n>.mp3` and `alignment/<n>.json` under `videoWorkDir(slug)` for each segment.
- AC-STE-664.6: A 401 or 403 refuses in the NFR-10 shape naming the provider and its key variable; a 429 or 5xx is retried after 1s, 2s and 4s (injected wait asserts the schedule) and then refuses; a success on a retry returns normally.
- AC-STE-664.7: `music.source: elevenlabs` makes one music request whose duration equals the video's planned length; `file` returns the committed track path and makes no request; `none` returns no track and makes no request.
- AC-STE-664.8: No test in this FR opens a network connection: every adapter takes an injected fetch, and the tests assert on the recorded requests.
- AC-STE-664.9: Mutation-verified: dropping the `<break>` rewrite turns AC-STE-664.3 red, and skipping the retry turns AC-STE-664.6 red; each mutation is asserted applied before its test runs.

## Technical Design

A provider interface with two adapters under the shared video module, each taking an injected fetch and wait. Alignment normalization is a pure function per provider. Keys come from the env reader in STE-663 and are passed in, never read from the process environment.

## Testing

Recorded fixture responses per provider; request recorders; injected wait for the backoff schedule; a shared contract test over both adapters.

## Notes

Lessons from the nexera run: eleven_v4 ignores SSML breaks; per-segment synthesis with alignment drives anchor cuts.

## Implementation notes

- Google adapter XML-escapes a raw <break/> in script text and only recognises [short pause] as two exact tokens — left open after the operator-approved third fix round; not an AC failure
- the ElevenLabs music prompt carries no style; non-401/403 4xx responses fall through to a missing-field error; the network-failure message lacks a Refusing: line — left open after the operator-approved third fix round; not an AC failure
