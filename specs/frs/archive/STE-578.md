# Tracker-orphan import asks before it writes

## Summary

The reconciliation preamble imports every tracker ticket that has no local spec file, writing a file and then pushing a rewritten description back to the ticket. With one tracker per repo that is merely surprising. With two repos sharing a tracker it is destructive, because every ticket belonging to the other repo looks like something this repo forgot. The import now asks first, and the clause claiming a guard against clobbering is deleted, because no such guard exists.

## Requirement

The reconciliation preamble must not import a tracker-only orphan without an explicit, per-orphan operator answer, and its prose must stop citing a clobber guard that the import path does not have.

## Acceptance Criteria

- AC-STE-578.1: § 0.5 of `skills/spec-write/SKILL.md` contains no occurrence of `existsSync` and none of `STE-135`, paired with a presence assertion that the tracker-orphan clause carries an explicit refusal-to-auto-import phrase and routes consent through `resolveInterviewAnswer` into `requireOrRefuse` with `defaultValue: undefined`. The absence half alone is satisfied by deleting the clause outright, so it never ships without its partner; the `defaultValue` obligation is asserted too, because a default lets the auto-approve marker silently perform the very import this FR removes.
- AC-STE-578.2: `skills/spec-write/SKILL.md` measures exactly 358 split-lines after the edit (`body.split("\n").length`, which is `wc -l` plus one), the milestone-attachment paragraph still resolves to line 111, and line 26 carries no module path (a slash-joined identifier ending in `.ts`). The edit is one line for one line; an insert or a delete above line 111 fails this AC even when the total stays 358.
- AC-STE-578.3: The two substring assertions pinning `existsSync` and `STE-135` in `tests/spec-write-preamble-reconcile.test.ts` are deleted rather than satisfied. A grep for `existsSync` in that test file returns zero, paired with the file still carrying more assertions than it had test blocks, so deletion cannot be mistaken for gutting the file.
- AC-STE-578.4: The FR body names STE-284 and states which of its two decisions this FR reverses and which it preserves. The reversal is the silent tracker-to-local import; the preserved invariant is that the gate probe never mutates.
- AC-STE-578.5: Local-only orphans and milestone mismatches keep their existing prompt behaviour byte-unchanged, mode-none stays vacuous, and § 0.5 keeps its position between § 0 and § 0a. Each is pinned separately.
- AC-STE-578.6: `reconcileTrackerLocal` remains the single shared source of truth for drift, the `/gate-check` probe over it still never mutates, and the `tracker_local_reconciled` emission contract is untouched — an import that now happens only on consent still emits the token when at least one FR or milestone is imported.

## Technical Design

Measured at HEAD, with controls:

```
grep -c existsSync adapters/_shared/src/import.ts                    -> 0
grep -c existsSync adapters/_shared/src/reconcile_tracker_local.ts   -> 3   (control: the search fires)
grep -c listEpics  adapters/_shared/src/attach_project_milestone.ts  -> 7   (control)
```

`adapters/_shared/src/import.ts:24` imports only `unlinkSync, writeFileSync`. Line 81 writes unconditionally; line 84 is `await provider.sync(spec)`, the outward write. STE-135 is the post-STE-76 resolver lookup contract in `adapters/_shared/src/resolve.ts`, not a clobber guard, so the parenthetical is false on both halves. The gate lives in `adapters/_shared/src/auto_answers.ts` and `adapters/_shared/src/requires_input.ts`; neither path may be named on line 26, because that line already classifies as ordered and its module lacks a front door. STE-284 made two decisions; this FR reverses one and preserves the other. Reversed: the silent tracker-to-local import. Preserved unchanged: the gate probe over the reconciliation is read-only and never mutates.

Add a refusal-phrase presence assertion, a 358 split-line assertion, a line-111 anchor assertion, a no-module-path assertion on line 26, and separate untouched-clause pins for the local-only and milestone-mismatch branches. ## Notes

Reverses a deliberate STE-284 decision, so the reversal is named in the FR rather than applied silently. STE-33, which forbids archival from auto-importing, is the existing precedent for refusing an implicit import.
