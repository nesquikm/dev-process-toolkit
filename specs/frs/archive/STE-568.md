# The docs tree stops describing a toolkit that no longer exists

## Summary

Sixteen drifts across the docs tree. An operator or author follows these as instructions, so a stale one costs a wrong action.

Retired shapes are still taught as current. One count is forty percent off, and one budget invites an author to write 142 lines a gate then rejects. Two docs describe a three-stage cycle that has four. Several pointers no longer resolve.

The shape is the same throughout: prose accurate when written that nothing re-reads.

## Requirement

No live doc instructs a reader toward a retired path, a retired convention, or a pointer that does not resolve, and the counts these docs state are derived from the things they count.

## Technical Design

Two of these fixes are sweeps and the rest are edits, and the sweeps are the part worth building. A corrected sentence is true today; a reader over the doc tree is what reds the next drift, and every finding here is a sentence that was true when written.

Counts are graded against their sources, not against each other. Grading two documents against each other is what let one figure drift forty percent while its sibling stayed correct — both agreed with the copy nearest to hand.

The citation reader resolves paths as written and does not follow renames: a citation that resolves only through `--follow` is still one a reader cannot chase.

## Testing

The sweeps run over the live doc tree rather than a fixture, because the assertion being made is about the shipped documents and a fixture would only prove the matcher compiles.

Each sweep pairs its absence assertion with a positive assertion of the replacement text. An absence check alone is satisfied by deleting the section.

The count legs read their source of truth in the same test that reads the doc, so the two are compared within one run and neither can be stale relative to the other.
