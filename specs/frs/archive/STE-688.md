# The bug FR guide says a TODO regression fails probe 88

## Summary

The guide for writing a bug FR says each bug needs a regression criterion that names a test.
It does not say what happens when that criterion is left as a to-do note.
The gate fails such a criterion, so an author learns this only when the gate turns red.
This fix adds the missing sentence to the guide, so the guide matches the gate.

## Requirement

### Steps to reproduce

1. Open `docs/resolver-entry.md` § Bug FR body.
2. Read the rule for the `Regression:` criterion.

### Expected

The rule says a `Regression:` criterion with no body, or with only a TODO marker, fails probe #88 until it names a test, as the probe has done since STE-681.

### Actual

The rule says only that a bug FR carries a `Regression:` criterion naming the test. The TODO case is not mentioned.

## Acceptance Criteria

- AC-STE-688.1: Regression: `tests/m_292387-ste-688-todo-regression-guide.test.ts › the bug FR body section names the TODO regression failure` fails before the fix and passes after it.
- AC-STE-688.2: `docs/resolver-entry.md` § Bug FR body states, beside the existing `Regression:` rule, that a `Regression:` criterion with no body or with only a TODO marker fails probe #88 until a test is named.
- AC-STE-688.3: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the trunk baseline by name.

## Technical Design

### Root cause

STE-681 taught probe #88 to reject an empty or TODO-only `Regression:` body, and edited the guide only for where Root cause belongs. Nothing pinned the guide to the new rule.

## Testing

A prose pin reads the section and looks for the sentence beside the existing rule.

## Notes

Found during the M_0cac80 delivery run.

## Implementation notes

- The regression test failed before the sentence was added and passes after it; two controls guard the matcher.

- The guide says a TODO Regression: fails probe #88 until a test is named, but the probe accepts any non-blank, non-TODO body — the sentence is exactly what the AC requires; tightening the probe is a separate change
