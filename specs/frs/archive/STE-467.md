# /implement Phase 3 best-practices conformance lens

## Summary

Review is where house rules earn their keep. When the catalog has entries, the implementation review reads the scope-matched documents directly and files violations as ordinary review concerns inside the existing bounded self-review loop — no new agent, no new hard gate, and a loud literal token when the lens legally skips.

## Requirement

An `/implement` Phase 3 conformance lens over `specs/best-practices.yaml`: deterministic scope-glob preselection, direct doc reads (no research fork — per the standing operator ruling that research forks stay out of /implement), violations filed as review concerns in the bounded loop, MUST-emit disposition tokens per the STE-373 no-silent-skip lesson.

## Acceptance Criteria

- AC-STE-467.1: Phase 3 lens: when the manifest has ≥ 1 entry, select entries whose `scope` globs match the FR's changed files (entries without `scope` always apply), read the curated docs directly, and file violations as review concerns.
- AC-STE-467.2: MUST-emit disposition pair in the /implement closing summary: `best_practices_lens_applied` XOR `best_practices_lens_skipped_no_manifest` — literal backticked tokens registered in the canonical capability map and the closing-summary probe sites; no silent skip.
- AC-STE-467.3: Lens concerns ride the existing bounded 2-round resolve-or-escalate review loop — never a new blocking gate, never an auto-fix outside the loop.
- AC-STE-467.4: The lens prose block and both disposition tokens are grep-pinned by meta-tests; NFR-1 line caps green on every touched SKILL.
- AC-STE-467.5: Project-local smoke fixture asserts the lens/disposition surface and is mutation-verified; SMOKE_LEGS untouched.

## Technical Design

Selection is deterministic (glob match via the STE-465 module against the FR's changed-file list, run via bun — not re-derived in prose); judgment is LLM-side inside Stage B where review already lives. Registering the two capability keys touches `closing_summary_capability_keys.ts` + the /spec-write § 7 static map + probe #44 sites. The `skills/` STE-token ceiling has ZERO headroom — offset any new tracker-ID tokens.

## Testing

`bun test`; meta-test grep pins on the lens block + both tokens; capability-key registration tests; smoke fixture with mutation check.
