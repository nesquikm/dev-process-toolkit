# The docs name the archive-only pass and stop calling the session-blind leg the only one

## Summary

The last release let an archive-only commit or pull request through with no fresh gate or review run.
Most pages describing those gates still omit that pass.
Two pages also say a gate skips evidence only when it cannot see the session.
That is no longer true.
The hooks reference lists the allowed archive edits without two that the code accepts.
This fix brings every one of those pages in line with the shipped gates.

## Requirement

Every surface that describes the commit gate or the pull request gate names the archive-only pass as a second way through with no evidence. No surface says the session-blind leg is the only way a gate passes without evidence. The hooks reference's allowed-edit list matches the classifier.

## Acceptance Criteria

- AC-STE-705.1: Each of these surfaces names the archive-only pass of the commit gate, the pull request gate, or both, as it describes them: the repo-root `CLAUDE.md` `hooks/` bullet; the `README.md` structure tree's `hooks/` entry; `templates/CLAUDE.md.template` § Gates on these chains; `docs/honored-contracts.md` (both gate mandates); `docs/setup-reference.md` (the gate list); `docs/workflow-overview.md` (both gate paragraphs); and `skills/pr/SKILL.md` (the spec-review hook paragraph).
- AC-STE-705.2: `templates/CLAUDE.md.template` no longer says the gates fail open only when they cannot see the session; it names the archive-only pass beside that leg.
- AC-STE-705.3: `docs/hooks-reference.md` no longer calls the missing-session leg the one fail-open leg or the only leg on which a guard passes without evidence; it names the archive-only pass as the other one.
- AC-STE-705.4: The allowed-edit list in `docs/hooks-reference.md` says an appended `## Implementation notes` section may be followed only by blank lines or a token-stats block, and that a complete new token-stats block appended at the end of the file is allowed.
- AC-STE-705.5: A new test asserts the phrase `only leg on which a guard passes without evidence` appears in no file under `docs/`, `templates/` or `skills/`, nor in the repo-root `README.md` or `CLAUDE.md`.
- AC-STE-705.6: The AC-STE-700.9 doc test gains needles for the appended-block wording of AC-STE-705.4.
- AC-STE-705.7: The `m_a41431-ste-573` tests (AC-STE-573.3 and AC-STE-573.4) stay green unchanged.
- AC-STE-705.8: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the trunk baseline by name.

## Technical Design

Prose edits only. Each surface gains one sentence naming the archive-only pass and pointing to the hooks reference for its allowed-edit set; nowhere is that set restated. The two false claims are rewritten to name both evidence-free legs. Code comments in the hook sources that say the one fail-open leg are reworded in the same change.

## Testing

One negative phrase test, two added needles in the existing doc test, and the existing announcement pins unchanged.
