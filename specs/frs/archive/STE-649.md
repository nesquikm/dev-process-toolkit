# The tracker-write gate covers every link writer and names true causes

## Summary

One Atlassian linking tool passed the tracker-write gate ungraded, and a link could name its unowned side by an opaque id and ride the owned side through.
The gate now covers that tool under both server spellings and refuses any Jira-item side it cannot resolve from a key or a browse URL.
The ownership refusal routes by verdict, and three receipt refusals name their real cause: two checkouts of one repository, an unreadable receipt directory, another session's receipt.

## Requirement

- **Gate the missing writer.** The hook gates `addTeamworkGraphContext` under both server spellings.
- **Resolve every link side.** A side that must be a Jira item resolves only from a key or a `/browse/<KEY>` URL. An unresolvable side refuses the link even when the other side is owned. Atlas, goal and remote-link targets are not ticket subjects.
- **Complete the inventory.** The tool inventory lists every live tool of both servers.
- **Route the ownership refusal by verdict.** The refusal routes through `ticket_ownership decide` and says which verdicts confirm and consent refuse.
- **Name the real cause.** The receipt refusals name it: two checkouts of one repository versus two repositories (D-5), an unreadable receipt directory with its errno (D-6), and another session's receipt (D-7).

Covers A7 (low), A8 merged with C-OWNR (low), and A9 (D-5), A10 (D-6), A11 (D-7) (low). Amends STE-607 §1/§2 (the gated write list, and link subjects): the archived §1 list of 26 names becomes history. Retires KNOWN DEFECTS D-5, D-6 and D-7 of STE-616: per R4 each bullet gains "Fixed in `STE-649` (v2.92.0)".

## Technical Design

Add addTeamworkGraphContext to the Atlassian write list after createIssueLink and regenerate the hooks.json matcher. Resolve subjects per side: both createIssueLink sides are Jira items; for addTeamworkGraphContext the object always is, the target only for the links/blocks jira-work-item relationship types; the existing one-owned-side link rule then applies. Recapture the tool inventory (Atlassian 41, Linear 68), add two Linear read tools, and mirror the grader. The ownership remedy routes by verdict, spelling the decide shape literally. D-5 runs git-common-dir per tagged root on the refusal path only; D-6 separates read from parse throws; D-7 records foreign-session announcements.
