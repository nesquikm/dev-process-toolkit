# Every gate waits out lag alike, and hook and grader read one envelope and the latest answer

## Summary

The test-driven commit gate now waits out a lagging transcript the way the other two command gates do, through one shared waiting rule.
A label write can no longer skip its consent and merge checks by carrying an extra key, and a later Skip answer withdraws an earlier Join.
The grader applies the hook's rule against creating a milestone twice, and a link or relation write no longer rides one owned ticket onto one it does not own.

## Requirement

- **One lag wait for every command gate.** The gate-check, spec-review and tdd commit gates share one bounded-wait helper. It re-reads only while a receipt run of that gate is unresolved, never re-runs the fail-open leg (a re-read that finds no transcript leaves the graded miss standing), and ends in the same lag refusal.
- **One labels-write envelope.** The hook and the grader decide what a Jira labels write is through one exported predicate. Format keys (`contentFormat`, `responseContentFormat`) do not change the verdict, and a labels write carrying any other field key on a joined container is refused rather than falling through to the ticket gate.
- **The latest answer governs.** When several asks answer the same consent subject, the latest answered ask before the gated call decides, in every hook consent check and in the grader.
- **The grader mirrors the container prior-create rule.** A milestone or Epic create after a settled, lost or parallel create of the same container is a finding, as the hook refuses it.
- **Links and relations grade every side they write.** A `createIssueLink` carrying a comment needs every side owned. Linear relation fields on `save_issue` are read as link sides by both hook and grader, and owning a relation target never permits writing an unowned issue.

Carries over M_163656's review items TW-1, TW-2, the cross-ask consent twin, TW-9 and TW-8, and F6 (the created-route derivation duplicated between hook and grader) where it folds in.

## Technical Design

Lift the STE-650 loop out of requireSkillToolUse into one helper taking a re-scan and grade function, keeping the wall-clock deadline, the lag-explainable test, the own-run pending test and the FO-1 break; requireTddEvidence waits on door one before asking door two. Export a labels-envelope predicate beside the shared ownership predicate; the hook's joined-labels gate fires on any labels write, then refuses extra field keys. Consent readers take the latest subject-naming ask before the gated line. The grader's container branch gains the prior-create check with a container comparator. Link sides add relation targets; a comment demands every side.
