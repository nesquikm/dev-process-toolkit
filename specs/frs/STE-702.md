# The pull request gate's archive-only pass grades the branch the pull request opens

## Summary

A pull request whose changes only archive specs may open with no fresh spec review.
The gate decides that from the local branch alone.
A remote branch can hold more commits, pushed from another clone.
The pass then covers code nobody reviewed.
A command naming two different bases is graded against the default branch only.
This fix grants the pass only when the remote branch matches the local one and every named base is archive-only.

## Requirement

### Steps to reproduce

1. Clone one bare remote twice, as clones O and W. In O, archive one FR on branch `fix/x` and push it.
2. In W, check out `fix/x`, add a source file, commit and push. Leave O unfetched.
3. Run `pre-pr-spec-review` in O on `gh pr create --fill` with no spec-review evidence.
4. Separately, on an archive-only branch whose diff against `release/1` carries code, run it on `gh pr create --base release/1 -t t -b b || gh pr create -t t -b b`.

### Expected

Both commands are refused for want of spec-review evidence.

### Actual

Both exit 0. Step 3 grades O's stale local branch. In step 4 two distinct bases collapse to none, so only the default branch is graded.

## Acceptance Criteria

- AC-STE-702.1: Regression: `tests/m_9261c7-STE-702-pr-archive-only-remote.test.ts › a remote head ahead of the local branch gets no pass` fails before the fix and passes after it.
- AC-STE-702.2: Regression: `tests/m_9261c7-STE-702-pr-archive-only-remote.test.ts › two distinct bases are each graded` fails before the fix and passes after it.
- AC-STE-702.3: The archive-only pass also requires `git ls-remote <remote> refs/heads/<branch>` to print exactly one sha equal to local `HEAD`, where `<branch>` is the checked-out branch and `<remote>` is its configured `branch.<branch>.remote`, else `origin`. A detached HEAD, a missing remote branch, a different sha or a failed `ls-remote` withholds the pass, and the normal evidence check runs.
- AC-STE-702.4: `pr_target_repo.ts` exposes every distinct base the command's creations name, with a creation that names none counted as the default branch. The pass is granted only when the branch is archive-only against every one of them; one creation with one base behaves as today.
- AC-STE-702.5: The existing AC-STE-700.5 permit tests move their fixtures from a fake https remote plus `update-ref` to a `file://` bare remote that the branch is pushed to, in the same change, and stay green.
- AC-STE-702.6: A forbid twin runs the AC-STE-700.5 permit leg after `git remote set-head origin -d` with no `--base`, and is refused for want of evidence.
- AC-STE-702.7: Archived `AC-STE-700.5` in `specs/frs/archive/STE-700.md` gains an appended clause `*(Amended by STE-702 (vX.Y.Z): the default branch is read from refs/remotes/origin/HEAD, and the pass is withheld when that ref is absent.)*`, with `vX.Y.Z` the release that ships this FR, and no other byte of that file changes.
- AC-STE-702.8: All legs run through the shipped `pre-pr-spec-review.sh` wrapper. Removing the remote-head check, or grading only one of several bases, turns at least one named test red.
- AC-STE-702.9: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the trunk baseline by name.

## Technical Design

### Root cause

`isBranchArchiveOnly` diffs merge-base..HEAD in the local checkout, and nothing ties HEAD to the remote branch the pull request opens from. `pr_target_repo.ts` sets `base` to null unless every creation names the same one, and null means the default branch.

The fix adds a remote-head equality check beside the classifier call, and a `bases` list on the target that the hook loops over. Nothing changes in the classifier.

## Testing

Temporary repositories with a real bare remote, two clones and the verifier's command shapes, driven through the shipped wrapper, plus mutation controls.

## Notes

Origin: verified M_a5dc12 follow-ups. The remote check costs one local-protocol call on a file remote and one network call otherwise, only on the archive-only path.
