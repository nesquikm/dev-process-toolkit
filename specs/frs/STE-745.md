# The /implement report fits its caps, and fixture 15a grades the whole report

## Summary

The closing report of an implementation run broke the sentence cap on every leg.
On one leg it also ran past the line cap.
The skill names the caps but gives no shape to fit them.
It now gives a short lead-in template and states both caps.
Smoke fixture 15a also cut the report so that two required sections fell away.
It now grades the whole final message.

## Requirement

`/implement`'s closing report carries a lead-in that fits the stage caps, and smoke fixture 15a grades the whole final `/implement` message.

## Acceptance Criteria

- AC-STE-745.1: `skills/implement/SKILL.md` step 14 and `docs/implement-reference.md` state the lead-in budget: at most three sentences, each at most `PLAIN_SENTENCE_WORD_CAP` (20) words, inside the stage's whole-report line cap. They give one literal lead-in template, and every sentence of that template fits the cap.
- AC-STE-745.2: A committed model report built from the template, with both cap-exempt sections and the fence, exits 0 from `stage_block_adoption.ts --report`. The same report with a 23-word lead-in sentence exits 1 and names the sentence cap.
- AC-STE-745.3: Smoke sub-fixture 15a's **Source** names the whole final assistant message of the `/implement` capture as the subject. The phrase "from the last `stage-status-block` fence opener's paragraph onward" is gone.
- AC-STE-745.4: A committed `/implement` capture fixture, extracted by the new 15a rule, yields a subject that exits 0 when the report is healthy. A test proves that the old cut of the same capture drops a cap-exempt section.
- AC-STE-745.5: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the baseline by name.

## Technical Design

Prose and fixture change only. The template lives in the SKILL step and the reference doc, and a test reads both and runs each template sentence through `longSentences`. The 15a extraction runs `extractAssistantText` and keeps the last assistant message whole.

## Testing

A template-fits test, a grader test on the model report, and an extraction test on a committed capture.

## Notes

Conformance 2026-11-17 F2 and F6.
