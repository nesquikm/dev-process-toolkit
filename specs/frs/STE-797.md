# A shipped Epic closes when the call carries its attribution key

## Summary

A shipped milestone's Epic could not be closed, although the close module wrote its receipt.
The Atlassian tools now accept an attribution key that says who made the call.
The write gate read that key as an extra edit, so the receipt did not count.
The gate now reads it as metadata on every Epic and label check.
The refusal also stops naming an old wrapped command after a later plain run.

## Requirement

The tracker-write gate and its live grader treat the Atlassian `actionSource` input as call metadata, and the refusal stops citing a rejected deciding command that a later plain run of the same module superseded.

## Acceptance Criteria

- AC-STE-797.1: `actionSource` is an envelope key in `adapters/_shared/src/join_consent_ownership.ts`: `isStatusOnlyTransition` accepts a `transitionJiraIssue` input carrying it beside `cloudId`, `issueIdOrKey` and `transition`, and `labelsEnvelope` does not count it as an extra key.
- AC-STE-797.2: With an intact `epic-close` receipt for the key announced in the session, the gate permits a status-only `transitionJiraIssue` that also carries `actionSource: "model_tool_call"`, through the shipped `.sh` wrapper. Its twin with no `epic_close.ts` run is refused, and adding `fields` or `update` beside `actionSource` is still refused.
- AC-STE-797.3: The Epic edit check accepts `actionSource` beside its other envelope keys, in the hook and in the live grader alike, and both read one shared key set rather than two copies.
- AC-STE-797.4: The refusal's "not a plain invocation" note leaves out a rejected command when a later Bash command in the session ran the same deciding module in the accepted shape. A rejected command with no later accepted run of its module is still reported, and the count and the cited latest command cover only the commands still reported.
- AC-STE-797.5: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the trunk baseline by name.

## Technical Design

Add `actionSource` to `ENVELOPE_KEYS` and export one `EPIC_EDIT_INPUT_KEYS` and the status-only set from the shared module, so the hook and the grader import them instead of keeping copies. `scanAnnouncements` records each rejected command with its transcript line and module; the note filters out entries followed by an accepted run of the same module.

## Testing

New STE-797 suite on the STE-699 world fixture: permit with `actionSource`, its no-receipt twin and the `fields` twin through the `.sh` wrapper; the grader twin; and a transcript with a wrapped run then a plain run, plus its control with only the wrapped run.
