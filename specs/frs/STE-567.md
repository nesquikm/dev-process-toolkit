# The front door describes what is actually behind it

## Summary

The two documents a reader meets first both describe a toolkit slightly different from the one that ships.

The sentence above the workflow diagram promises eighteen skills and the full path; the diagram draws fifteen. That framing turns an omission into a misdirection. One skill is justified nowhere, and the agents table lost the row for the agent that performs an entire audit.

Underneath, the count probe grades tokens against each other, never the tree.

## Requirement

Every count the front door states is derived from the thing counted, every user-invocable skill is reachable from the README by some route the README itself offers, and the structure blocks describe the tree that ships.

## Technical Design

The checks land in `public_surface_count_drift` (probe #57), which already walks these files and both trees. A new probe number costs roughly two dozen pinned sites and would buy nothing — the inputs are already open in the module that would pay it.

The README-surface derivation goes into its own module, because parsing a diagram is a different kind of reading from counting directory entries.

The reachability check reports per skill, not per count. `/best-practices` went unnoticed precisely because every README count was internally consistent while one skill was unreachable from all of them; a checker comparing two numbers reproduces that blind spot exactly.

## Testing

Both halves of the split get a mutation, and each mutation is first measured against unmodified code to confirm it currently returns clean. The finding here was not that a check was wrong but that a check did not exist, and a new assertion that would also pass on the old code proves nothing.

The reachability leg is exercised with a skill removed from the diagram and from the prose in turn, so the two routes are shown to be independently load-bearing rather than one masking the other.

## Notes

The prose paragraph beneath the README "Latest:" banner stays hand-maintained by design, per the Release Checklist. Nothing in this FR changes that; the counts corrected here are the ones with a reader.
