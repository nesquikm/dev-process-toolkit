# The container listing grades only this project's open tickets

## Summary

The shared-container listing offered tickets that were closed, already archived here, or from another project, and read the toolkit's own review label as a sibling repository's tag.
It now offers only this project's open tickets that no local FR binds, refuses a page from another project or team in a shared binding, and never mistakes the review label for a sibling.
After a milestone ships, the drift probe reports its still-open Epic, and the ship checklist names closing it.

## Requirement

- **Toolkit labels.** The toolkit's own `needs-technical-review` label is never read as a sibling repository's tag.
- **Closed and archived tickets.** Closed tickets, and tickets bound by an archived FR, are neither offered as imports, consented to, nor reported as drift.
- **Foreign pages.** In a shared binding, the listing, consent, drift and import surfaces refuse pages from another project or Linear team.
- **Open Epics after ship.** Probe #49 reports an open Epic whose milestone has shipped here, as a warning in an unshared repository and as info in a shared one.
- **Ship checklist.** The /ship-milestone checklist names closing the Epic.

Covers C-F5, C-ORPH, C-P49 and C-EPIC (all low). Amends STE-605's definition of a sibling.

## Technical Design

Export `TOOLKIT_LABELS` naming its writer; only foreignLabels changes, classifyTicket stays byte-identical. ContainerTicket gains `closed: boolean | null` (Jira statusCategory done; Linear statusType completed/canceled or completedAt/canceledAt set; null is open). listOrphans' bound set uses the previous FR's `includeArchive`; closed tickets render `(closed)`, are counted and refused by consent. Drift adds a `closed` never-orphan class and skips closed tickets. `assertListingProject` (project plus Linear team key, shared bindings only) guards listing, consent, the drift view and import. Probe #49 maps each open Jira container to its token and checks the archived plan.
