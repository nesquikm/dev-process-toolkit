# A bug's regression test is proved red before the fix, and /debug proves it without a commit

## Summary

An external contribution makes a bug fix prove its test.
Each bug test must fail before the fix and pass on it.
The audits count a bug case without that proof as unproved.
The debug skill gains a path for a reported bug.
One step there asked for an unapproved commit.
It now proves the test in a throwaway copy of the tree.

## Requirement

A bug's regression test is fixed only when it is shown RED on the code before the fix and GREEN on the fix. `/tdd`, the two spec-review audits and `/debug` say so and enforce it (external PR #137). No step of that proof asks the agent to make a commit the operator has not approved (Core Principle 4).

## Acceptance Criteria

- AC-STE-817.1: For a `kind: bug` FR, the `/tdd` test-writer proves each `Regression:` AC's test RED on the code before the fix and takes its tree snapshot only after a bug-case RED; the implementer proves the fix load-bearing by undoing it from Stage RED's tree and reporting the outcome (`skills/tdd-write-test/SKILL.md`, `skills/tdd-implement/SKILL.md` and their agents).
- AC-STE-817.2: The `/tdd` spec-review audit and the `/spec-review` audit count a bug AC that carries no red-before proof as unproved, and the `/tdd` halt report keeps the undo outcome (`skills/tdd-spec-review/SKILL.md`, `skills/spec-review-audit/SKILL.md`, `adapters/_shared/src/tdd_halt_report.ts`).
- AC-STE-817.3: `skills/debug/SKILL.md` carries `## A reported bug`: a reported bug is fixed only when a test is RED at its assertion before the fix and GREEN on it, and a bug FR's fix goes through `/implement <FR-id>`.
- AC-STE-817.4: The `/debug` "fix made before its test" path never tells the agent to commit. For a fix that is not committed yet it works in `git worktree add --detach <dir> HEAD`, copies the test in and runs it (RED at its assertion), then copies in every path the fix changed, untracked ones included, runs it again (GREEN), and removes the worktree. The path for a committed fix is unchanged.
- AC-STE-817.5: `tests/bug-regression-proof-contract.test.ts` pins the AC-STE-817.4 wording and pins that `skills/debug/SKILL.md` no longer carries the sentence "commit a fix that is not committed yet".
- AC-STE-817.6: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the trunk baseline by name.

## Technical Design

The PR's four commits land as written, with the author rewritten to the contributor's GitHub noreply address. Our change is one sentence in the `/debug` SKILL plus the pins that read it. HEAD is the code before an uncommitted fix, so a detached worktree of HEAD needs no new ref. The fix's paths come from the working tree's change list, untracked files included, and deletions are applied in the worktree too.

## Testing

Update the `/debug` pins in the bug-regression contract test to the new wording, and add one pin that the commit sentence is absent. The PR's own suites stay green.
