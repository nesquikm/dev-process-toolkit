# /pr can open a pull request as a draft

## Summary

The pull-request skill has no draft vocabulary at all — a sweep of its skill file and its tracker-mode reference returns nothing. A pipeline run in which the operator has reserved merges therefore has no safe terminal state to stop at other than a normal open pull request, which reads to reviewers as ready for review.

Draft is the state that says built but not yet claimed ready, and it is the terminal state a never-merge run actually wants. Without it, the pipeline's safest configuration still produces an artifact that misrepresents its own readiness.

## Requirement

The pull-request skill can open a pull request in draft state on request, and the choice is visible in its report.

## Acceptance Criteria

- AC-STE-496.1: `/pr` accepts an explicit request to open the pull request as a draft.
- AC-STE-496.2: The default remains non-draft: a run that does not ask for a draft behaves exactly as it does today.
- AC-STE-496.3: The draft choice appears in `/pr`'s closing report, so a reader can tell which state was opened without checking the host.
- AC-STE-496.4: Draft support works on the tracker-mode pull-request path as well as the tracker-less one.
- AC-STE-496.5: When the host or CLI cannot open a draft, `/pr` says so rather than silently opening a normal pull request.

## Technical Design

A sweep of `skills/pr/SKILL.md` and `docs/pr-tracker-mode.md` for "draft" returns zero hits, so this is a new capability rather than an exposure of an existing one.

AC.5 is the load-bearing one. A host that cannot open a draft — an unsupported repository type, or a CLI without the flag — must produce a visible statement rather than a silent downgrade, because a silently non-draft pull request in a never-merge run is exactly the misrepresentation this FR exists to prevent. A silent skip is worse than a loud failure.

AC.2 keeps this additive: no shipped run changes shape unless the draft state is asked for.

Scoped deliberately as a general `/pr` capability rather than a `/deliver`-side preference. Having `/deliver` instruct its workers to open drafts without `/pr` documenting the capability would reproduce, in a new place, exactly the producer/consumer asymmetry this milestone's hand-off FR exists to repair.

## Testing

Coverage for the explicit draft request, for the unchanged non-draft default, and for the report line on both paths. Tracker-mode and tracker-less paths both exercised. Unsupported-host path asserted to surface a statement rather than downgrade silently, with the silent-downgrade case mutation-verified to go RED. `bun test` full root.
