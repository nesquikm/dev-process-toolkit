# Session lookup finds transcripts under dotted and long paths

## Summary

The report skill finds the current session by turning the working directory into a folder name.
It replaced only slashes, while Claude Code replaces every character that is not a letter or digit.
So a directory with a dot in its path pointed at a missing folder.
The report then lost its transcript and its evidence check without saying so.
The lookup now follows Claude Code's rule, including its cut for long paths, and checks it found the right session.

## Requirement

- **Same rule.** The folder name matches the one Claude Code writes, for dots, underscores, spaces, non-ASCII text and paths over the length cap.
- **Right session.** Two different directories can share one folder name, so a candidate transcript whose recorded working directory differs is skipped.
- **One rule.** The skill text and the test helpers use the same function rather than restating the rule.

## Acceptance Criteria

- AC-STE-677.1: `cwdToSlug` replaces every character outside `[A-Za-z0-9]` with `-`: `/a.b` → `-a-b`, `/x/app_platform` → `-x-app-platform`, `/a b` → `-a-b`, `/w/b/.s11/r` → `-w-b--s11-r`; the existing examples still hold.
- AC-STE-677.2: A slug longer than 200 characters is cut to its first 200 and given the same hash suffix Claude Code adds; a test pins a cwd over 200 characters to a value whose source (Claude Code version and how it was observed) is recorded in this FR's notes.
- AC-STE-677.3: `findCurrentSession` and `selectIncidentSession` skip a candidate transcript whose first recorded `cwd` differs from the requested cwd, and return null when none remains; a fixture with `/w/a.b` and `/w/a-b` sessions in one folder returns the matching one.
- AC-STE-677.4: `skills/report-issue/SKILL.md` states the new rule (or names `cwdToSlug` as the source), its doc pin in `tests/report-issue.smoke.test.ts` follows in the same commit, and the old-rule comments in `find_current_session.ts` are corrected.
- AC-STE-677.5: The slug helpers in `tests/_live_bundle_fixtures.ts` and `adapters/_shared/src/shared_tracker_live_grader.ts` call the shared `cwdToSlug` instead of their own copies.
- AC-STE-677.6: Restoring the slash-only rule reddens at least one test, and removing the cwd check reddens the collision fixture.
- AC-STE-677.7: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the trunk baseline by name.

## Technical Design

One replacement over the whole cwd, then the length cap with the hash suffix, in the existing function. Candidate filtering reads the first line of each transcript that records a `cwd` before ranking by modification time; a transcript that records no cwd is kept.

## Testing

Pure rule cases, the long-path case, and the collision fixture in a temporary config folder. The doc pin moves with the prose.

## Notes

Reported in gist 9b9c2f8c. The rule was checked against 63 local project folders on 2026-10-16.

Long-path source: Claude Code 2.1.301, read from its installed binary with `strings` on 2026-10-16. It cuts at 200 and appends `-` plus base-36 `Math.abs` of a 32-bit hash of the cwd. The pinned value came from running that extracted code.
