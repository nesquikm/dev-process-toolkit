# A typed answer naming the key adopts the ticket

## Summary

On a shared tracker, a ticket with no repo tag needs the operator to adopt it first.
Today only a click on the Adopt option counts, so a typed yes forces the question again.
This lets a typed answer count too, but only when it names the ticket key and says yes.
An answer that says skip, no or not never counts, so the old misreading cannot return.

## Requirement

GitHub issue #118: an explicit typed approval ("post it") was not taken as `Adopt <KEY>`, so the same question was asked a second time only so the operator could click. AC-STE-607.4 and AC-STE-650.8 deliberately made free text non-consent, and D-8 once read `Skip <KEY>` as consent, so the new rule must be narrow, shared, and pinned against those cases.

## Acceptance Criteria

- AC-STE-694.1: For a question that names `<KEY>` and offers `Adopt <KEY>`, an answer other than that exact label counts as consent only when all three hold: it contains `<KEY>` as a whole word (case-insensitive), its first word is one of adopt, yes, approve, post or go (case-insensitive), and it contains none of skip, no, not, don't, dont or cancel as a whole word.
- AC-STE-694.2: A matrix test pins the verdicts: `adopt NEZ-496`, `yes, post to NEZ-496` and `Adopt nez-496` consent; `post it`, `Skip NEZ-496`, `don't adopt NEZ-496`, `adopt NEZ-4960`, `yes adopt NEZ-496 but not now` and `NEZ-496` withhold.
- AC-STE-694.3: Only the `Adopt <KEY>` label gains the typed rule. `Import`, `Join`, `Create` and `Skip` keep the exact-label rule: a typed `yes import NEZ-1` still withholds Import consent.
- AC-STE-694.4: The rule has one home, an exported function in `adapters/_shared/src/join_consent_ownership.ts` that `perQuestionConsent` calls. The hook and the live grader give identical verdicts on the AC.2 matrix, and a source test fails if either re-implements it.
- AC-STE-694.5: Free text the operator types outside a question (the `consentedBefore` operator-text path) keeps its exact-label rule, and the D-8 regression stays green.
- AC-STE-694.6: The archived STE-607 and STE-650 FRs gain an amendment line on AC.4 and AC.8 naming this FR. The tests that pinned "free text is not consent" are updated to the new matrix, not deleted.
- AC-STE-694.7: The hook's refusal remedy text says a typed answer counts when it names the key and says yes.
- AC-STE-694.8: Mutation battery: dropping the key check, the affirmative-first-word check or the negation check each reddens a named test.
- AC-STE-694.9: Gate: `bun test` from `plugins/dev-process-toolkit` reports 0 fail with skip identities equal to the baseline, and `/gate-check` is clean.

## Technical Design

Add `typedAdopts(answer, key)` beside `perQuestionConsent` and accept it there only when the label is `Adopt <KEY>`. The key comes from the label, never from the answer. Whole-word matching uses token boundaries so `NEZ-4960` never matches `NEZ-496`.

## Testing

A pure matrix test on the predicate, the same matrix through the hook transcript fixtures and the live grader, plus the D-8 and exact-label regressions.

## Notes

Approved in the 2026-10-22 brainstorm. Scope choice made at spec time: Adopt only, since the design named Adopt.
