# The AC-STE-609.9 control compares against main as it stands

## Summary

A gate-check structure test compared the skill against trunk and then added this milestone's new probe row on top by hand.
That held only while trunk lacked the row; after the merge trunk carries it, the row was counted twice, and trunk went red.
The fix derives the rows a branch adds from its difference with trunk, so the comparison holds on trunk and on any branch that registers a new probe.

## Requirement

- **Derived, not typed.** The control's expected probe-row positions are main's positions plus exactly the rows the working tree adds over main, computed from the diff; no row number or line is hard-coded.
- **Holds on main.** On a tree equal to main the control passes.
- **Holds on a branch.** On a tree that registers one new probe row the control passes.
- **Still a control.** Moving an existing row's position still fails it.
- **Marker kept.** The AC-STE-659.3 amendment marker stays, with a note naming this fix.

## Acceptance Criteria

- AC-STE-660.1: The `(control)` test in `tests/m_685ff6-ste-609-prose.test.ts` asserts `positions(now)` equals `positions(main)` plus exactly the probe rows present in the working tree and absent from `main`, derived from the two texts; the literal `[173, "86"]` appears nowhere in the file.
- AC-STE-660.2: The control passes on merged main `33714e53`, where the working tree equals `main`.
- AC-STE-660.3: A fixture where the working-tree skill registers one extra probe row after main's last row passes the control's comparison helper.
- AC-STE-660.4: A fixture where an existing probe row moves to a different line fails the control's comparison helper.
- AC-STE-660.5: The AC-STE-659.3 amendment comment stays in the test and names AC-STE-660.1 as the fix that replaced the hard-coded row.
- AC-STE-660.6: `bun test` from `plugins/dev-process-toolkit` on the fix branch reports 0 failures, and its 16 skips are identical to main's by name.

## Technical Design

Extract the position comparison into a small pure helper inside the test file: given main's text and the working text, compute both position lists, take the working rows whose probe number main lacks as the added set, and assert the working list equals main's list followed by the added set in order. The control and the two fixtures call the helper; the split-line count assertion is dropped where an added row legitimately changes it, and kept for the main-equal case.

## Testing

The 609 suite itself carries the three legs: main-equal tree, one added row, one moved row. The full gate run confirms 0 failures and an unchanged skip set against main.

## Notes

Root cause: a branch-relative delta hard-coded into a test that measures against main. Twins 588 to 591 were swept and pass on main.
