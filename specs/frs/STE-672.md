# Suite-edit guards measure against a pinned commit

## Summary

One test went red on trunk right after the video release merged.
It checked a suite's edits by diffing against trunk, and once the branch merged there was no diff left.
The test now diffs against a fixed commit, so it reads the same before and after a merge.
A sweep finds any other test that needs a diff against trunk, and a check stops new ones.

## Requirement

- **Pin the base.** The m143-551 admission test and its mutation diff `tests/m143-ste-551-continuation-offers.test.ts` against commit `134fe2e6`, the v2.96.0 milestone's base and the same commit the AC-STE-618.8 freeze uses, never against `main`.
- **Not merge-base.** `git merge-base HEAD main` equals HEAD after a merge, so it would read empty again; it is not used.
- **Sweep.** Every test that asserts a non-empty diff against `main` is moved to a pinned commit. Assertions that a suite is unedited against `main` stay as they are, since they still catch edits on later branches.
- **Fence.** A check fails when a test asserts a non-empty diff against a moving ref.

## Acceptance Criteria

- AC-STE-672.1: The two m143-551 assertions in `tests/m_79b1f6-ste-590-offers-ask-the-gate.test.ts` diff against `134fe2e6`, held in one named constant; no assertion in that file requires a non-empty diff against `main`.
- AC-STE-672.2: The 590 suite passes on this branch and in a temporary checkout of merged trunk `24e25900` with the fix applied, both asserted by the test run recorded in the plan.
- AC-STE-672.3: The mutation test still reds when the marker is stripped from one hunk or an unmarked hunk is appended, measured against the pinned diff.
- AC-STE-672.4: A test scans `tests/` for an assertion that requires a non-empty `git diff` against `main` or `HEAD`, finds none, and a planted fixture proves the scan finds one.
- AC-STE-672.5: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the trunk baseline by name.

## Technical Design

Replace the moving ref in the two m143-551 assertions with a constant naming the pinned commit, matching how the freeze test pins its kickoff. Add a small scanner over the test tree for non-empty-diff assertions against moving refs, with a planted control.

## Testing

Run the 590 suite on the branch and in a temporary merged-trunk checkout; mutation controls; the scanner with a planted fixture; full gate.
