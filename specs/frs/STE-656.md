# Docs and archived specs say what the shipped code does

## Summary

Several documents still describe the toolkit before the last two releases.
Three skill pages and a source comment still call the branch-gate module a probe, the hooks reference lacks the receipt refusals the previous release reworded, the project template names only the copied install, and two archived specs carry contracts that later work amended without saying so.
This change corrects each one in place and repairs the two remedies of the binding probe that point at commands which write nothing.

## Requirement

- **No unregistered probe.** No skill page or source comment calls `commit_producing_skill_branch_gate` a probe or gives it a probe number.
- **Hooks reference.** The tracker-write gate section states the D-5, D-6 and D-7 refusals as they now read: the receipt location, an unreadable receipt directory, and another session's receipt.
- **Install shapes.** The CLAUDE.md template names both the copied cache install and the in-place directory-source install.
- **Archived amendments.** STE-603 (the floor wording) and STE-607 (the sections STE-649 amended) carry amendment clauses in the R4 pattern.
- **Probe #25 remedies.** The missing-project and key-prefix remedies name a route that actually writes the fix.
- **Consent docs.** The Import/Adopt consent docs say the key must appear in the question text, as the code requires.

Covers F8/TW-11, TW-7, TW-4 and the docs half of the M2 carry-overs.
