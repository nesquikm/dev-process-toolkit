# Bug FRs are recognised on import and graded by the gate

## Summary

Bugs that start in the tracker become bug FRs when they are imported.
A Jira bug, or a Linear issue with the bug label, gets the bug marker and the Fixed category.
A new gate check reads every active bug FR.
It fails when one lacks reproduction steps, expected and actual results, a root cause, or a regression criterion.
It also fails when a bug claims a feature-style changelog category.

## Requirement

- **Recognised.** Importing a ticket that the tracker calls a bug writes a bug FR.
- **Graded.** The gate checks every active bug FR for its bug sections and its regression criterion.
- **Coherent.** A bug FR's changelog category is `Fixed` or `Security`.
- **Quiet otherwise.** FRs without the bug marker, and archived FRs, are never graded.

## Acceptance Criteria

- AC-STE-680.1: `importFromTracker` writes `kind: bug` and `changelog_category: Fixed` for a Jira ticket whose `issuetype.name` equals the resolved bug type, and for a Linear issue whose labels include the resolved bug label; every other ticket imports byte-identical to today.
- AC-STE-680.2: An imported bug FR receives the four bug subsections and a `Regression:` AC, each holding a TODO marker when the ticket does not supply it.
- AC-STE-680.3: Probe #88 `bug_fr_shape` (severity: error) reports one NFR-10 violation per missing piece of each active `kind: bug` FR: Steps to reproduce, Expected and Actual present and not TODO-only; Root cause present, with the needs-technical-review placeholder satisfying it on a flagged FR; at least one AC whose body begins `Regression:`.
- AC-STE-680.4: The coherence arm flags `kind: bug` with a `changelog_category` outside `{Fixed, Security}`, and any `kind:` value other than `bug`; FRs with no `kind:` key and archived FRs are never graded.
- AC-STE-680.5: Vacuity is measured: `vacuous` is true exactly when no active FR carries `kind: bug`.
- AC-STE-680.6: `/gate-check` registers the probe as `call runBugFrShapeProbe(projectRoot)` from a module carrying an `import.meta.main` front door; probe #81 stays green; probe-count pins move by their own derivation, never by hand.
- AC-STE-680.7: Removing each probe check, or the import detection, reddens at least one test.
- AC-STE-680.8: `bun test` from `plugins/dev-process-toolkit` reports 0 failures, and its skip identities equal the trunk baseline by name.

## Technical Design

The import reads the issue type or labels off the fetched ticket through the bug resolver from the sibling FR. One probe module with two arms, shape and coherence, follows the probe #86 pattern: it renders violations from its own scan and measures vacuity.

## Testing

Import fixtures for a Jira Bug, a Linear Bug label and a plain task. Probe pass and fail fixtures per piece. A mutation battery.

## Notes

Depends on the sibling FR's frontmatter key and resolver.
