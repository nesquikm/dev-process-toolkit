# Implementation Plan

## M_a41431 — Gates that announce themselves {#M_a41431}

**Goal:** Every blocking gate the toolkit ships is announced on a surface an agent reads before it trips one, and the announcement is graded rather than remembered.

**Prerequisites:** None. Ships after M_645517.

**Release target:** the next patch after v2.80.4 — verify against `CHANGELOG.md` rather than trusting this line.

Three PreToolUse hooks refuse an action unless a specific Skill ran as a `tool_use` in the current session. The predicate is a substring pair on a single JSONL line: it cannot see a Bash call, a passing test run, or any output. Fail-open exists only for a missing or unreadable transcript. A fresh agent meets all three blind, mid-flow, after the work is already done.

The manual for them already exists and is correct. Nothing links it.

### The three gates

| Hook | Fires on | Requires |
|---|---|---|
| `pre-commit-gate-check` | a `git commit` Bash call | `/dev-process-toolkit:gate-check` |
| `pre-pr-spec-review` | a `gh pr create` Bash call | `/dev-process-toolkit:spec-review` |
| `pre-commit-tdd-orchestrator` | a `git commit` staging a source file with its test | `/dev-process-toolkit:tdd` |

All three exit blocking on the miss. The external report that surfaced this named two of them.

### Why this is a reachability bug and not a missing document

`docs/hooks-reference.md` documents all three, correctly, including the refusal text each one emits. A recursive grep for that filename across the docs tree, the skills tree, the templates tree, the README and CLAUDE.md returns nothing. A fourth document would land in exactly the same place. So the work is links in, links out, and announcements at the points of use — plus one reader, because a class of omission is not fixed by correcting one member of it.

### The risk this milestone runs

The subject is a shipped gate that no document announced in advance. The self-inflicted version of that is announcing two of the three, or adding a reader and forgetting to point it at the tree the change itself lands in. Five prior milestones in this repository reproduced their own defect. STE-573 exists to make the recurrence loud rather than to promise it will not happen.
