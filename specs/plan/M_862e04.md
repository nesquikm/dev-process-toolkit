# Implementation Plan

## M_862e04 — One Approval, One Act {#M_862e04}

**Goal:** A release skill's content approval covers the content and nothing else, and opening a pull request is authorised by its own approval. Carries with it the enabling fix that the milestone surfaced: the target-repo sweep stops forbidding the very declaration the toolkit ships.

**Prerequisites:** Ships FIRST of the three, before M_0c14d0 and M_f1f569. STE-600 is what turns the gate green for every later worker, so nothing else can start ahead of it.

**Release target:** v2.84.1 — a patch bump, because both FRs are Fixed. Verify with `inferBump` against the FR frontmatter and CHANGELOG rather than trusting this line.

**Routing note:** This plan deliberately declares NO `target_repo:`. The milestone's work lands in two trees — STE-600 in this repository, STE-599 in a sibling that has no toolkit installed — and `target_repo:` routes a whole milestone to one tree, so declaring it here would route this milestone as reduced and strand STE-600's implement and ship stages. The sibling half is a task inside the normal in-repo chain, carrying its own pull request against that repository.
