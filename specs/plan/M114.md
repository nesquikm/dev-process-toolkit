# Implementation Plan

## M114: Linear acceptance-criteria checkboxes {#M114}

**Goal:** Restore the Linear acceptance-criteria completion-state round-trip. The push/create path currently writes ACs as plain bullets, so Linear renders no togglable checkbox and the documented `pull_acs` / `push_ac_toggle` round-trip is inoperative for Linear-created tickets. This milestone makes the Linear push path emit each AC as an unchecked task-list checkbox on create (idempotent; existing checked state preserved), closing the push-side gap STE-190 (M52) left open. Jira's plain-bullet AC section is correct and stays untouched.

**Prerequisites:** none — the pull-side tolerance shipped in STE-190 (M52); this milestone adds the push-side checkbox emission that same FR scoped out. STE-211 / STE-398 share the push helper and must keep passing.
