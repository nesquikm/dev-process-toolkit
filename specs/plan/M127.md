### Notes

- **Two directions of defect, not one.** Six of these are false REDs against healthy subjects. Two are false GREENs: group 2's sub-fixture 2a matched spuriously in the same run its sibling 2c false-failed, and 2b passed for a reason its own assertion does not check. A fixture that can pass without evidence is the more dangerous half, which is why STE-483's non-vacuity requirement runs in both directions.
- **Out of scope by construction.** Fixture 10a's carve-out is not tightened. STE-456 AC.2 states the reason: a group that false-reds on a healthy short run gets disabled, which is worse than the hole. STE-486 extends the carve-out to Phase 4 rather than removing it from 10a.
- **Recurrence.** Fixture 3c has now drifted twice — it already carries a note about a prior doc-drift on the same surface. STE-485 AC.5 generalises the fix (verify each asserted token against its emitting source) because instance-level corrections have demonstrably not held.
- **Prior art applied.** STE-445 supplies the harness-with-halt shape. STE-423 supplies STE-487's tracker-segment rule, which this run falsified for Phase 9. STE-456 AC.7 and STE-461 AC.12 supply the extract-and-execute method; STE-461 AC.13's erratum supplies the mutate-the-right-subject constraint.
