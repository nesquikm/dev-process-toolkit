# Implementation Plan

## M_4df444 — Runs that clean up after themselves {#M_4df444}

**Goal:** A smoke or conformance run leaves nothing behind that nobody can name: every child session is recorded when it is spawned, a passed leg removes its own sessions when the loop ends, a crash or an old run is cleaned by hand from the same code, and the stdin-fed spawn fence that caused the 2026-09-11 runaway is refused before it runs.

**Prerequisites:** Ships after M_79b1f6 (v2.83.0). Nothing else is in flight.

**Release target:** v2.84.0 — a minor bump, because all three FRs are Added. Verify with `inferBump` against the FR frontmatter and CHANGELOG rather than trusting this line.

### Risks

| Risk | One side | The other side |
|------|----------|----------------|
| The hook also guards the maintainer's own sessions in this repo | That is the point: the runaway came from an interactive driver session | A legitimate stdin-fed background script in this repo is refused; the remedy is to run it from a file |
| Pinned surfaces | Six tests pin the loop's skill and `leg_prose_surfaces` parses its spawn fence | STE-595 and STE-594 edit the same fences, so they land in that order and each re-runs the pinned suites |
| Attribution without a session id | Shell snapshots and config temps are matched by birth time and liveness only | The cleanup reports that attribution class instead of presenting it as identity |
| The release check deletes real files | The operator chose a real sweep of the 27 old smoke dirs as the bar | Dry run first, exact paths only, survivor check after |

### Deliberate deferrals

| Deferred | Why not now | Revisit when |
|----------|-------------|--------------|
| Trimming cmux's registry and workstream log | cmux rewrites both continuously, so editing them live races it | If cmux exposes a supported way to forget sessions |
| A non-macOS CLI cache location | The maintainer runs macOS; the cache root is injectable for tests | When a second maintainer platform appears |
| Cleaning automatically after a reboot | A runaway that ends in a reboot never reaches Termination; manual mode covers it | If a second runaway happens |
