# Implementation Plan

## M140 — External Link Liveness {#M140}

**Goal:** An external resource a spec depends on is checked when it is cited, and a dead one fails the gate.

**Prerequisites:** None. Independent of M138 and M139.

**Release target:** v2.78.0 (provisional, minor — both FRs are Added). Retargeted from v2.77.0, which M139 shipped as on 2026-09-04; the number was provisional and the collision is the second in this program.

`scan_design_references.ts` returns false for any token carrying a URL scheme, so an external link under a reference section is not merely unchecked — it is invisible to the only probe that walks those sections. No FR has ever checked a network URL.

The fetch lives in `/spec-write`, not in the probe. Every probe in this toolkit is a pure file read, and probes #68 and #69 restate that in shipped prose; a fetching probe would overturn a bar in a direction the gate cannot defend, since a machine with no egress would be indistinguishable from a machine facing dead links. So the skill checks at authoring time and records its verdict in the spec, and the probe grades the record. The record is git-tracked and reviewable, which a cache is not — and `.dpt/` caching is refused twice already, by AC-STE-11.1 and again by STE-394.

Severity splits on what the author declared. A link an implementer must open is load-bearing; a terms page is a courtesy.

### Tasks

- [x] STE-542 — stop dropping URL tokens in the reference scanner
  verify: a URL row is emitted with its own kind; every repo-relative path row stays byte-identical
- [x] STE-542 — classify each link one at a time, defaulting to informational
  verify: the prompt is an ask tool call per link, never one batched prompt
- [x] STE-542 — write the verdict and its timestamp into the spec beside the link
  verify: the recorded line round-trips through the scanner that will grade it
- [x] STE-542 — map responses to verdicts
  verify: 401 and 403 read reachable; DNS failure, connection refused, 404, 410 and any 5xx read dead
- [x] STE-542 — record an unrunnable check as unchecked, never as dead
  verify: with no egress the row reads unchecked and a capability row says the check did not run
- [x] STE-542 — stay vacuous when a spec cites nothing external
  verify: no interview, no request, no record, asserted as a request count of zero
- [x] STE-542 — widen the optional-section closed set in the layout reference
  verify: the superseded "only optional sections" sentence is asserted gone, as when Summary widened it
- [x] STE-543 — repair any dead probe-count leg before bumping it
  verify: the existing count assertion is shown to fail on a wrong count first
- [x] STE-543 — register the probe and grade recorded verdicts across active and archived specs
  verify: dead-and-required fails; dead-and-informational, stale and unrecorded-informational report
- [x] STE-543 — fail a required link that carries no record at all
  verify: the fixture asserts the failure names the URL and its file and line
- [x] STE-543 — prove the check can fail
  verify: removing the verdict comparison turns a recorded-dead required fixture green
- [x] STE-543 — keep the probe a pure file read
  verify: a test asserts the module opens no socket and the shipped purity prose needs no edit
