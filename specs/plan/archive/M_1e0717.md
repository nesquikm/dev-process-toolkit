# Implementation Plan

## M_1e0717 — Feature explainer videos {#M_1e0717}

**Goal:** Give the toolkit a /video skill that turns a shipped feature into a short explainer video, built the same way every time. The 2026-10-08 nimbra AI Coach video was assembled by hand across four workers. This milestone keeps that pipeline and its lessons in the toolkit (voice, music, cuts, banned effects), and keeps each project's look and recorder setup in the project, so the next video matches the last.

**Prerequisites:** v2.95.1 merged at 134fe2e6 (PR #108).

**Release target:** v2.96.0, a minor: new Added FRs and one consumer-artifact migration.

**Operator rulings.** 2026-10-12 brainstorm (via /deliver, source gist 321b5769): hybrid ownership (approach 3 of 3): the toolkit owns providers, cache, renderer, checks and the offer, and the project owns style, scenarios and recorder choice. Recorders: web, ios-sim, android-emu, footage and a command contract, picked per project. Two approval stops: script, then final cut. Offer at /ship-milestone only. Music: ElevenLabs, a committed file, or none. Work dir: .dpt/video/work/<slug>/, ignored. One milestone (operator choice over a 3-milestone split). Keys in project-local .dpt/.env, which must be ignored. Title and codename composed automatically.

**Migration:** `dpt-gitignore-video` adds `.env` and `video/work/` to the toolkit-owned `.dpt/.gitignore` in existing projects.
