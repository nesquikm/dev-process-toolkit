# Implementation Plan

## M_f1f569 — Guards That Grade The Right Tree {#M_f1f569}

**Goal:** The pre-commit guards stop being decided by an accident of geometry. They classify against the repository the commit will actually write to, say so out loud when they cannot tell, and stop being unsatisfiable for a fix that has no feature request behind it.

**Prerequisites:** Ships THIRD, after M_862e04 (v2.84.1) and M_0c14d0 (v2.85.0). The milestones touch disjoint files, but ship serially — parallel milestones collide on probe-count pins and the release files.

**Release target:** v2.86.0 — a minor bump, because STE-598 is Added and STE-597 is Fixed. Verify with `inferBump` against the FR frontmatter and CHANGELOG rather than trusting this line.

### Risks

| Risk | One side | The other side |
|------|----------|----------------|
| A second accepted proof is as plantable as the token it joins | The workaround the guard exists to prevent gets a legitimate-looking sibling | The threat model is self-discipline, not an adversary; this is recorded in STE-598 rather than assumed away |
| Parsing command shapes will not cover every invocation | An exotic quoting or scripted commit still will not resolve | That case is the advisory leg, which says so rather than passing silently |
| Widening what the hooks match makes them fire where they never did | A previously silent commit path now blocks | The new matches are only ever commit-bearing commands, and the unresolvable leg never refuses |
| The guards are edited by a session the guards are guarding | A hook change can break the ability to commit the hook change | Land the resolver and its tests before the evidence change, and keep the hand-commit route available |
