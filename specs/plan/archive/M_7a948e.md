# Implementation Plan

## M_7a948e — Releases for repos whose tags own the version {#M_7a948e}

**Goal:** A project whose git tags own the version can close a milestone with `/ship-milestone`. An opt-in `## Docs` flag, `changelog_unversioned`, writes the milestone's entries under `## [Unreleased]`, bumps no version and stamps `shipped_in: unreleased`, which every stamp reader accepts only under the flag. Refusal #4 stops demanding a child listing for a numeric milestone under a shared Jira binding.

**Prerequisites:** v2.99.2 merged at 67579d8f (PR #117).

**Release target:** v2.100.0, a minor: two Added FRs and one Fixed. Verify against CHANGELOG.md before shipping.

**Operator rulings.** 2026-10-21 /deliver run from gist 271417a0. Asked: the opt-in is a `## Docs` flag, not a new Release Files kind; the stamp is the literal `shipped_in: unreleased`; it joins the one shared stamp grammar, flag-gated in every reader (approach 1); the children fix covers numeric milestones under a Jira shared binding only.

**Migration:** none — the flag is opt-in and absent everywhere today.
