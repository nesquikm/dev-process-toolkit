# Implementation Plan

## M_b054b1 — The tracker gate speaks both Atlassian surfaces {#M_b054b1}

**Goal:** The tracker-write gate, its live grader, the answer reader and the Jira adapter guide work on the Atlassian v2 tools as well as the v1 tools. A shipped Epic closes from either surface, and no Jira write reaches a shared project unchecked.

**Prerequisites:** v3.9.0 on main (49748968).

**Release target:** v3.10.0, a minor: one Security FR, three Fixed FRs and one Changed FR. Verify against `CHANGELOG.md` before the release.

**Operator ruling (2026-11-24):** full v2 support in one milestone; one shared translator for the hook and the grader; an execute operation the gate does not know is refused in a repository that declares a shared Jira target; a receipt from another plugin copy stays untrusted. The live check on a real v2 project stays STE-802.

**Evidence:** tool schemas, call inputs and answers recorded in local session transcripts of 2026-11-16 to 2026-11-24. No v2 server is connected to this repository, so no AC claims a live v2 call. The repository is public: fixtures carry invented keys, sites and account ids.

**Migration:** none — no consumer artifact changes shape.
