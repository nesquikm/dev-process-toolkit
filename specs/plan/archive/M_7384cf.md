# Implementation Plan

## M_7384cf — Bugs filed as bugs {#M_7384cf}

**Goal:** A bug written with `/spec-write --bug` is a bug everywhere. It carries `kind: bug`, lands in the tracker as a bug, has a body shaped for reproducing and fixing it, and works for QA authors under `--no-tech`. Bugs imported from the tracker are recognised, and the gate grades bug FRs.

**Prerequisites:** v2.98.1 merged at ab193898 (PR #113).

**Release target:** v2.99.0, a minor: two Added FRs. Verify against CHANGELOG.md before shipping.

**Operator rulings.** 2026-10-20 brainstorm, approach #2: an explicit `kind: bug` key, written only when set, with `changelog_category` defaulting to `Fixed` and still overridable. Tracker mapping uses defaults plus overrides (`jira_bug_issue_type:`, `linear_bug_label:`); a missing type or label refuses loudly. Bugs bind to a milestone like features. `--bug --no-tech` keeps the `chore/` spec branch; `/implement` gets `fix/` from the category. Two FRs.

**Migration:** none — `kind:` is optional and absent on every existing FR.
