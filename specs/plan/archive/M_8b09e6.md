# Implementation Plan

## M_8b09e6 — Merge commits graded on their own changes {#M_8b09e6}

**Goal:** A merge or rebase onto main should not ask for TDD evidence for tests that main already shipped. A user report (gist 9b9c2f8c, v2.98.0) showed the commit hook refusing a plain merge commit over main's tests, leaving only a false proof or a shell bypass. The same report found that the report skill loses its transcript when the working directory contains a dot.

**Prerequisites:** v2.98.0 merged at e8e41932 (PR #112).

**Release target:** v2.98.1, a patch: two Fixed FRs. Verify against CHANGELOG.md before shipping.

**Operator rulings.** 2026-10-16 brainstorm: both defects in one milestone. A waived path matches a merge head, the rebase head or git's own merge result byte for byte. Hand-edited resolutions still need evidence. A waiver passes with a visible Reminder, never silently, because a stash-commit merge can forge one. Rebase is covered; squash, cherry-pick and revert stay refused and are named in the remedy. The reachability guard was rejected: every local ref can be forged and it refuses local merges.

**Migration:** none — no consumer artifact changes shape.
