# Implementation Plan

## M_b1c081 — A tool call written twice is one call {#M_b1c081}

**Goal:** A transcript that records one tool call twice is read as one call. The commit gate then keeps a /tdd run's window open past its own receipt, whichever order the two copies land in.

**Prerequisites:** v2.101.0 merged at 91c506c4 (PR #122); main at e861e5ac.

**Release target:** the next patch after v2.101.0: one Fixed FR. Verify against CHANGELOG.md before shipping.

**Operator rulings.** 2026-10-26 brainstorm, from a field report against v2.101.0: copies sharing one id merge into one call that keeps the earliest line and the timed copy's stamp; the same collapse covers every per-id collection the Skill-call scan builds (approach 2). The repository is public: no client names, private domains, emails, report links, home paths or real session ids in any file.

**Migration:** none — a reading rule inside the bundled hooks; no consumer artifact changes.
