# Implementation Plan

## M137 — Say Less {#M137}

**Goal:** Cut length on the three human-facing surfaces — live stage output, FR files, milestone plans — without dropping any fact a reader needs.

**Prerequisites:** None.

**Release target:** v2.75.0 (provisional, minor — four FRs are Added).

Measured baseline at v2.74.0, 2026-08-31. Nothing constrains live narration length. FR files average 1365 words: Summary 210, Technical Design 234, Notes 93, Acceptance Criteria 596. Probe #67 caps Summary at six PHYSICAL LINES while real summaries run three to four lines carrying 160 to 198 words, so it has twice the headroom it needs and has never fired on length. Plans average 1972 words, a third of it tasks; the rest is prose under headings that vary between plans.

The approach extends the existing probe #67 scanner rather than registering a new probe, so the probe id, its severity and the README count of 81 stay put and no pinned-count cascade fires.
