# Implementation Plan

## M_7bc805 — Capture what a run actually did {#M_7bc805}

**Goal:** Record what each run did, opt-in and privacy-safe. That covers when its tool calls ran and returned, and which review rounds changed the tree. It also covers whether each gate passed on a named input. A measurement spike comes first and decides what the later FRs may record. Gate receipts gain an outcome and an input key. A capture hook adds tree state the transcript cannot hold. A timeline reader derives the rest from the transcript.

**Prerequisites:** M_94e6f7 (v3.0.0) is merged. It ships `specs/settings.yaml`, `loadProjectSettings` and `writeProjectSettings` in `project_settings.ts`, and `docs/settings-reference.md`. M_94e6f7's closing dogfood task is done before this milestone starts. This repo then runs v3.0.0 from a refreshed plugin cache and has been migrated by /upgrade. Its tree holds no moved setting in two places, and probe #69 reports no pending migration. STE-714 is merged before any other FR of this milestone starts. Its decision table fixes branches in STE-716 and STE-717.

**Release target:** v3.1.0, a minor release after v3.0.0, with four Added FRs. Verify against CHANGELOG.md before shipping.

**Operator rulings.** 2026-11-04: the four-milestone programme is approved, with this milestone second. No setting may lower generated-code quality or disable a deterministic gate. The toggle lives in the `tracking` section of `specs/settings.yaml`. Timestamps and error flags are derived from the transcript. The live hook is used only for tree state at call time, the diff size at a commit, and durability. Error state is `is_error`, not an exit code, unless the spike proves one exists. Duration comes from Pre/Post rows paired by `tool_use_id`, with orphans handled. Tree hashes are taken only on commit-class Bash and Skill calls. The hook has a p95 bound and a short timeout, in seconds. With the flag off, the hook exits before any heavy import. Gate receipts are extended, not duplicated. Rows live under `.dpt/ledger/` and hold no raw commands, cwd or branch names. Hook-count pins move. The repository is public, so only synthetic ids appear. Gate-check freeze (R5) is pre-granted once for this milestone. Re-base the AC-STE-618.8 KICKOFF once at this milestone's gate-check edit commit, listing the new permitted lines. The re-base lands as its own reviewed commit with the freeze test green (STE-715). Dogfooding (R2): M_94e6f7 ends with this repo refreshed, upgraded and checked for leftovers, so this milestone starts on a migrated tree.

**Decisions.** These are self-decided defaults, recorded 2026-11-04. The capture key is `tracking.tool_calls`, beside `tracking.token_stats`. Writers write to the home the loader reports. The key has no legacy home, and the CLAUDE.md binding stub (M_94e6f7 ruling R1) carries no tracking key. This milestone, not M_d1b4b7, supersedes the requirements.md Out of Scope line "No hooks/bin/.lsp.json in the plugin" (STE-716). M_d1b4b7 keeps the other lines it rewrites. Outcome receipts cover all three gates: gate-check, tdd and spec-review. The STE-716 latency bounds stay as drafted until a task re-reads them against the spike's no-op baseline. The spike runs interactively with the operator at the keyboard. Its recorder is registered in user scope and removed afterwards. STE-717 records why zero-yield rounds come from result blocks and tree digests, not the advisory notes file. Tracker ids are lowercased inside file paths when placeholders are filled.

**Migration:** none. `tracking.tool_calls` is a new optional key that defaults to false, and receipts gain fields that readers ignore. No consumer artifact moves.
